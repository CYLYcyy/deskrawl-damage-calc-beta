## 仍待验证的项与打桩方案

### 重点新增：静电与易伤内置 30% 的结构（相乘 vs 加算）

- 本框架：`A_indep=(1+0.3×易伤覆盖)×(1+静电项)`；本地：`T=1+0.3×易伤覆盖+静电项`。现状无直接实测，输出须标注所用口径。
- 打桩方案（遵循本仓库 `workflow.md` 原则：单变量对照、同状态锁定、比值优先、必给判读阈值、定标与验证分离）：
  1. 固定同一闪电技能 / 形态 / 元素 / 面板 / 装备，只读**非暴击白字**（若只能读暴击跳字则四组锁同一暴击档）。
  2. 2×2 四组读数：`D00`（易伤关、静电 0 层）、`D01`（易伤关、静电 N 层）、`D10`（易伤开、0 层）、`D11`（易伤开、N 层），易伤覆盖率 `a` 四组一致。
  3. 取静电比值 `R_off=D01/D00`、`R_on=D11/D10`，记 `V=1+0.3a`：
     - 相乘：`R_on≈R_off`（静电因子与易伤无关）；
     - 加算：`R_on≈1+(R_off−1)/(1+0.3a)`，即 `R_on<R_off`。
  4. 判读阈值：相差 <3% 判相乘；≥8% 且 `R_on` 接近上式判加算；3%–8% 数据不足，提高 N（满 10 层）/ 覆盖率后重测。示例 a=1、静电满层：相乘预测 `R_on≈R_off`，加算预测约小 9%。
  5. 对称复核：`R_vuln(0层)=D10/D00` 与 `R_vuln(N层)=D11/D01`，相乘时相等、加算时后者更小。
  6. 静电项形式（线性 `0.066N` 或逐层相乘 `1.066^N−1`）不影响判据——只看比值是否随易伤变化。
  判读完成后先更新 `merge-decisions.md` / `known-issues.md` / `game-mechanics.md`，再改主体 Step 6.5 并重算历史结论。
