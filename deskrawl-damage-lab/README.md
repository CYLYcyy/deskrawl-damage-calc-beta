# 桌面破坏神 · 伤害实验室 (Deskrawl Damage Lab)

纯静态、零依赖的伤害计算工作台 + 可调用的知识库智能体。打开 `index.html` 即可用，数据版本 **1.1.11a（2026-11-12）**。

## 目录结构

## 伤害模型（十个乘区）

```
单次伤害 = [（武器伤害 + 平伤）× 技能倍率]
         × (1 + 主属性 / 100)
         × (1 + 元素伤害% + 全伤害%)              ← 加算，同一乘区
         × (1 + 暴击率 × 暴击伤害% × (1 − 目标暴伤减免))
         × (1 + Σ 条件伤害%)                       ← vs 精英/健康/减速…内部加算
         × (1 + 基础/强力/特殊 类型伤害%)
         × (1 + 技能专属加成%)
         × (1 + 易伤 30% + 静电 10%/层)            ← 目标"受到伤害"通道，内部加算
         × (1 − 护甲或魔抗 / (护甲或魔抗 + 50 × 攻击者等级))
```

### 三个容易搞错的地方

1. **全伤不是独立乘区**。官方逐步表写的是 `× (1 + 元素伤 + Bonus All Damage)`，与元素伤加算（已拍板，无独立乘区分支）。
2. **易伤 30% 与"对易伤目标 +X%"是两回事**。前者是目标受伤通道（×1.3），后者是攻击者条件伤乘区（按覆盖率折算）。
3. **静电只加闪电**，每层 10%（1.0.4 真源实锤：`AmplificationPercent.Base=0.10`、`FilterByDamageType=true`，旧 5%/6.6% 已弃用），与易伤在同一括号内加算。

其它上限：暴击率 85%、冷却缩减 80%、减伤 90%；直伤声明 ±10% 浮动（当前引擎未采样），DoT 没有，也不吃类型伤。

## 怎么算

- **每跳倍率**：技能轴页的「单跳乘区验算」，逐行列出乘区与累计值，最后与引擎单跳对齐（误差 0）。
- **周期期望倍率**：一次完整法力循环的总伤害 ÷ 武器伤害。
- **秒伤**：0.05 秒步长逐帧模拟（冷却、法力、动作锁、DoT 刷新、buff 叠加、基础攻击自动攻击）。
- **词条倾向**：逐条试算"再加一条 ilvl700 中值词条"的秒伤增量，取最高。
- **天赋**：贪心 + 单点交换精修，自动满足专精行互斥与门槛。

## 配置存档

顶栏「配置」按钮打开存档抽屉：

- **自动草稿**：任何改动 0.7 秒后写入本机，刷新、关标签都不丢。
- **多存档**：命名保存，列表显示职业、秒伤、时间；同一存档可覆盖或另存。
- **导出 / 导入 JSON**：跨设备迁移；导入时会按当前数据版本重新校验，非法字段直接丢弃而不是报错。
- **分享链接**：整套配置 base64 编码进 URL，对方打开即是同一套构筑（约 850 字符）。
- 存的是**全部配置项**：职业、元素、主类型、装备 15 项数值、4 个技能槽、天赋每点、套装与件数、传奇勾选、仆从等级/缰绳/装备/星级、敌人模型与覆盖率、难度、GCD。

存档格式带 `schema: 2` 与 `game` 版本号。换版本后加载旧存档会提示「已按当前数值重算」，技能/天赋里已不存在的条目会被清掉。

## 对敌模型与覆盖率

对敌页有五个**场景预设**（单个小怪 / 精英 / 区域首领 / 群怪 / 木桩）。点一下会同时填好生命、精英标记、目标数量、难度与六项覆盖率，并在每个输入框下方写明依据。

覆盖率按**职业攻击距离**分两套（`data.js` 的 `CLASS_RANGE`：战士/武僧近战，法师/猎手远程）：

| 场景 | 远处 | 健康 | 受伤 | 易伤 | 逻辑 |
| --- | --- | --- | --- | --- | --- |
| 单个小怪（秒杀） | 远程 100 / 近战 0 | 100 | 0 | 35 | 落地即死，没有残血段；远程来不及被贴脸 |
| 精英（5–10s） | 远程 5 / 近战 0 | 20 | 25 | 30 | 快速贴近，只有开场算远处；血量线性下降 |
| 首领（20s+） | 远程 5 / 近战 0 | 15 | 25 | 45 | 长战易伤能续；定身免疫记 0 |
| 群怪 6 只 | 远程 60 / 近战 0 | 50 | 20 | 50 | 多目标易伤命中率更高 |
| 木桩 | 远程 100 / 近战 0 | 100 | 0 | 60 | 不动、不掉血，站桩续易伤 |

**两种口径不要混用**（对敌页底部有对照卡）：

- **周期期望 / 秒伤**：用上面的覆盖率加权，回答「打这个场景平均每秒多少」。总览、秒伤曲线、词条收益排行都走这个口径。
- **单跳伤害**：不摊覆盖率。技能轴页的「单跳乘区验算」可切到「单跳瞬时」，假设这一发命中时目标带易伤、处于健康/受伤段、被减速定身且在远处，条件项按 100% 计——这是**上限参照**。实战请按目标此刻的真实状态取 0 或 1。

## 智能体

网页「智能体」页是本地版：检索知识片段 + 直接调引擎算数，不联网。

命令行版（可被任意 agent 调用）：

```bash
node agent/tools/calc.mjs --class sorcerer --element lightning --enemy boss
node agent/tools/calc.mjs --class warrior --hit w_flame --electro 0
node agent/tools/calc.mjs --class warrior --affix weapon
node agent/tools/calc.mjs --class monk --legendaries arcaneedge,thirdbeat --minion icehound --minion-level 10
node agent/tools/calc.mjs --check        # 乘区连乘自洽校验

# 装备数值 / 技能等级 / 符文 / 静电双口径
node agent/tools/calc.mjs --gear 840,legendary
node agent/tools/calc.mjs --class warrior --skill-level w_val:20
node agent/tools/calc.mjs --class warrior --runes RareRune_WarriorBasicAttack:6
node agent/tools/calc.mjs --class sorcerer --taken-mode multiply
```

把 `agent/SKILL.md` 放进 `~/.codebuddy/skills/deskrawl-damage-analyst/SKILL.md`，即可作为技能被加载。
未明项（静电×易伤结构、横扫/CDR 取值、仆从被动是否进面板、充能指环 K 等）的裁决原则与实测步骤见 `agent/references/measurement-guide.md`；证据采信度排序与 11 条用户拍板见 `agent/SKILL.md`。

## 仆从模型

- 被动随技能等级成长；缰绳的 +5 对每个被动/主动技能都生效，可超过等级上限。
- 1–10 级：5 级解锁仆从装备槽。
- 传奇缰绳强化：**自身技能 +5 级**，可超上限，48 小时；仆从自身输出单列，不吃玩家乘区。
- 仆从主动技能（真源 16 只有 `Abilities`）倍率未展开、**不计入 DPS**；只做机制标注。不存在旧版编造的 `30% + 4%/级` 公式。

## 版本更迭

1. 改 `data.js` 的 `VERSION` 与受影响技能/天赋/词条的数值。
2. 新传奇写进 `LEGENDARIES` 的 `fx`（声明式增量），引擎按通用规则解释。
3. 官方改规则（乘区、上限、状态数值）改 `MECHANICS`。
4. 改动记进 `PATCHES`。
5. 跑 `node agent/tools/build-kb.mjs` 重建知识库，再跑 `node build-standalone.mjs` 重新打包根目录的 `deskrawl-lab.html`（**两步缺一不可，单文件是分发物**）。
6. 跑 `node agent/tools/calc.mjs --check` 确认自洽；发布前确认 `git diff --exit-code` 无残留（构建产物须与源码同步）。

## 已知边界

- 基础攻击按**自动攻击**处理，与动作条并行，只被引导技能打断。
- 护腿 / 肩甲是黑雾可重铸基底，词条池不设限；**披风是纯外观**，无属性、无词条、无被动。
- 传奇被动中标注 `modeled` 的（击杀后、站定、喝药、每 N 次触发）按假设覆盖率折算，不是实测。
- 不建模闪避、格挡、护盾、荆棘暴击的完整链路；防御属性只影响生存。
- 强力攻击的动作时长用「公共施放间隔」近似；实测重击约 1 秒时把它调到 1.0。
- 跨职业对比只在「同装备档 + 同敌人 + 同技能组」口径下成立，不是职业强度榜。
- 覆盖率是**时间占比**，不是触发概率；场景预设是"典型打法"的估计值，不是实测数据。换流派（例如把法师当近战打）后要手动改。
- 「远处」在旧存档里是布尔值，加载时会转成 100 / 0。
