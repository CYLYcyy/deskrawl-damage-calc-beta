# 未决项实测指引（统一操作模板）

> 落地用户原则：**未明项给选项卡让用户选他认为的口径，或录实测结果；Skill 遇到未明项要提示用户实测并给简单可行步骤。**
> 原则：**不静默采用、不编造**。系统默认值只是未裁决前的临时占位，绝不冒充权威；用户的一手选择/实测优先于社区二手记录，跨数据版本不过期。

## 0. 选项卡统一结构（每个未决项一张卡）

```
【未决项】<问题，如：静电 × 易伤是相乘还是加算>
【系统默认】<当前实现 + 依据 + 证据等级>（未裁决前的占位）
【你的裁决 · 三选一，必选其一】
  ○ 采用系统默认
  ○ 采用另一口径
  ○ 我实测过 → 展开录入实测结果
【实测录入】
  - 实测数值/观察：____（如 2×2 打桩的 R11/R00 比值）
  - 测量条件：技能__ / 元素__ / 白字还是暴击字__ / 易伤覆盖__ / 静电__层 / 敌人__ / 装备档__
  - 测量日期：____   [可选] 截图
【系统判定】按录入值自动判口径，卡面标「依据你的实测」
【操作】应用到当前构筑 / 应用到全部 / 恢复系统默认
```

**行为规则**：① 未裁决项常驻可见，不藏在文档里；② 选择即时进入计算，不同口径结果并排对比；③ 用户实测标"第一手"并覆盖默认；④ 选择与实测存入存档/分享码，版本更新保留实测；⑤ 记录"当前值 + 来源 + 日期"可回溯；⑥ 不同口径是**不同求解任务**，结果不可混比。

## 1. 通用打桩准备（所有跳字实测共用）

1. **固定变量**：同一角色、同一装备（换装前后只动被测项）、同一技能与等级、同一敌人预设；木桩用固定目标（不动、不掉血）。
2. **场景口径**：近战打木桩"远处"覆盖率填 **0**（贴脸打，吃不到远处加成）；远程按实际填。这是用户拍板，不是可选项。
3. **只看白字**：暴击跳字受暴率/暴伤影响，方差大；优先取未暴击的白字。必须看暴击字时，记录暴击伤害倍率并多次取样。
4. **多次取样**：每项至少 10–20 个跳字取均值；记录最大值/最小值供判断掷骰浮动（词条 roll ∈ [0.85,1.15] 在装备落地时已固定，同一件装备不浮动）。
5. **留证**：记录测量条件 + 日期 + 截图；录入时一并填写，否则无法复核。

## 2. 静电 × 易伤结构（2×2 打桩）

| 项目 | 内容 |
|---|---|
| 未决问题 | 目标受伤通道里，易伤 30% 与静电（5%/层、仅闪电）是**加算**还是**相乘** |
| 系统默认 | **加算**（当前 `engine.js` 实现：`1 + vuln + elec`）。相乘仅作为敏感性对照，不冒充系统默认。 |
| 可选口径 | 加算 / 相乘 / 我实测过 |
| 证据等级 | 结构本身**未实测**（A 级官方只给技能描述，未给乘区结构）；静电系数 **5%/层是用户拍板**（6.6% 已弃用），不再重复裁决 |

**操作步骤**

1. 用法师纯闪电技能（`s_electro` 电弧或 `s_storm` 闪电风暴），**不带任何混伤技能/装备**（静电只加闪电）。
2. 装备、天赋、被动全部固定；把其他条件伤（对精英/健康/减速/易伤目标 +X%）暂时置 0，避免污染。
3. 打同一木桩，记录四组**白字**均值：

| 组 | 易伤 | 静电层数 | 记录 |
|---|---|---|---|
| R00 | 无 | 0 | 基准 |
| R10 | 有（30%） | 0 | 易伤因子 `rV = R10/R00`，预期 ≈ 1.30 |
| R01 | 无 | 10 层（50% 闪电伤） | 静电因子 `rE = R01/R00`，预期 ≈ 1.50 |
| R11 | 有 | 10 层 | 组合因子 `rB = R11/R00` |

4. 判定：`rB ≈ rV + rE − 1`（≈1.80）→ **加算**；`rB ≈ rV × rE`（≈1.95）→ **相乘**。实测值录入后由系统按阈值自动判口径。
5. 注意：若易伤来源自带"对易伤目标 +X%"（攻击者条件伤），它会额外放大 R10/R11，必须先关掉；静电层数上限 10，超出无效。

## 3. 仆从被动是否进玩家面板

| 项目 | 内容 |
|---|---|
| 未决问题 | 仆从被动加成是否已包含在角色面板属性里（决定是否重复计入） |
| 系统默认 | **不重复计入**（按"与装备同池加算"推断，C 级） |
| 可选口径 | 进面板 / 不进面板 / 我实测过 |

**操作步骤**：① 记录裸角色面板（力量/敏捷/智力、暴击率、暴伤、对应元素伤）；② 带上目标仆从（出战、被动已升级），**其它装备/天赋/符文不变**；③ 再读同一组面板数值；④ 若面板数值变化 → 面板已含，计算器**不重复计入**；若完全不变 → 面板未含，按现有模型加算。⑤ 若同时带多只仆从，逐只单独测试以区分叠加。

## 4. 冷却缩减（CDR）上限 80% vs 85%

| 项目 | 内容 |
|---|---|
| 未决问题 | CDR 上限到底是 80%（本地实现/补丁）还是 85%（反编译 `CooldownReduction=0.85`） |
| 系统默认 | **80%**（本地 `data.js` 实现，待核对） |
| 可选口径 | 80 / 85 / 我实测过 |

**操作步骤**：① 准备多件带 CDR 的装备（单条 ilvl700 传奇中值 11.2%）+ CDR 宝石/药水，把总 CDR 堆到明显超过 85%；② 注意区分装备/宝石/药水/天赋来源，逐项摘除以定位封顶发生在哪一层；③ 读角色面板 CDR 数值，看停在 **80%** 还是 **85%**；④ 把面板值录入。证据：反编译 0.85（A）与本地 80（可能 1.0.2b 补丁）冲突，未裁决，以面板为准。

## 5. 横扫 10 级倍率（97 / 100 / 75）

| 项目 | 内容 |
|---|---|
| 未决问题 | 战士横扫（Cleave）10 级武器伤害% 取哪个值 |
| 系统默认 | **97%**（本地 `w_cleave`，但来源有 1 级偏移错误，未裁决） |
| 可选口径 | 97 / 100 / 75 / 我实测过 |
| 冲突背景 | AFK Meta 与 deskrawl.tools 均 **75%**；按 SO 公式 `Base+N×PerLevel = 0.50 + N×0.025` 应为 `70+10×3 = 100%`（1.1.11 改过基础/增量）；本地 `70+9×3=97%` 用了错误 N=9。三源冲突，**未裁决**。 |

**操作步骤**：① 战士角色把横扫升到 **10 级**（看技能面板等级数字，不要信 tooltip 描述里的 Base）；② 读技能面板显示的横扫伤害百分比（weaponDamage%）；③ 在 97/100/75 中选择与面板一致者，或录入自定义值 + 截图；④ 不要根据"版本链自洽"等推断替用户拍板。

## 6. 闪电风暴 10 级倍率（225% 优先）

| 项目 | 内容 |
|---|---|
| 未决问题 | 法师闪电风暴 10 级武器伤害% |
| 系统默认 | **225%**（SO 逆向 A 级，`Base=1.5, PerLevel=0.075`） |
| 可选口径 | 225 / 自定义（**218% 是第三方二手记录，已按用户拍板弃用，仅在用户本人一手实测时才录入**） |

**操作步骤**：① 法师把闪电风暴升到 10 级；② 读技能面板的伤害百分比；③ 若面板为 225% → 保持默认；若确实读到其它值（用户本人实测）→ 录入数值 + 条件 + 截图，标"用户实测（第一手）"并覆盖默认；④ 不要引用外部 skill 仓库的 218% 覆盖 A 级 SO 值。

## 7. 充能指环 K（技能伤害随法力）

| 项目 | 内容 |
|---|---|
| 未决问题 | 传奇"充能之戒"描述"技能伤害随当前法力最多 +50%"的系数 K 及口径（按当前法力%/固定档位？） |
| 系统默认 | **不计入**（描述口径不明确，避免脑补） |
| 可选口径 | 计入 / 不计入 / 我实测过 |

**操作步骤**：① 游戏内核对传奇被动**原文描述**，截图；② 固定技能/装备/敌人，分别在**满蓝**与**空蓝**打同一木桩，记录白字均值 `D_full`、`D_empty`；③ 比值 `K = D_full / D_empty − 1`，与描述"最多 +50%"对照；④ 若在不同法力百分比下线性变化，记录 25%/50%/75% 三个点验证是否线性；⑤ 录入 K 与测量条件。

## 8. 静电系数（已拍板，仅在本人实测时录入）

系数 **5%/层、最多 10 层**是用户拍板（6.6% 已弃用），**系统默认不再提供"6.6%"选项**。若用户自认有一手实测与之不符，可在选项卡选"我实测过"并录入跳字反推值；否则跳过此项。

## 9. 录入后的判定与回溯

- 用户实测/选择写入 `cfg().decisions[未决项id]`，进入 `score()` / `simulate` 参数；不同口径**并排展示敏感性值**。
- 卡面与结果卡显示"依据：系统默认 / 你的选择 / 你的实测"与录入日期。
- 数据版本更新时：用户实测项**保留**，系统默认项重新审视。
- Skill 侧行为：回答涉及未决项的问题时，**先说明当前采用口径与证据等级，再主动给出上述实测步骤**，不得把未裁决值说成事实。
