## 四、回答机制问题时的标准话术

1. 先查本表：**真源已实证**的，直接给值，标"真源实证"。
2. **冲突用户拍板/版本存疑**的，说："真源 1.0.3 给的是 X，但你的拍板是 Y，且真源版本落后于游戏，默认仍用 Y，X 作为候选项供你裁决"。
3. **真源也没有**的，说："真源 SO 无此数值，只有文案/推断，维持近似"，绝不编造。
4. 任何结论都带版本标注："真源 2026-10-16 dump（1.0.3）"。
