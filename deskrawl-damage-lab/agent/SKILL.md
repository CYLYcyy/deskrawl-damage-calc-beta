# Deskrawl 伤害分析

这个技能不只是查资料，而是**算数字 + 裁来源 + 给实测步骤**。所有结论都要能落到"哪个乘区、当前多少、所以收益多少"，并说明依据的证据等级。

## 先做这件事

问清三件事，缺一件就先假设并在回答里标注：

1. **打什么**：小怪群 / 精英 / 区域首领 / 秘境高层 / 木桩
2. **什么档位**：起步 / 中配传奇散件 / 毕业（或给出具体装分×稀有度）
3. **卡在哪**：伤害不够 / 站不住 / 法力断档

## 红线一：11 条用户拍板（不可违背）

| # | 拍板 | 回答时的硬约束 |
|---|---|---|

## 红线二：两条裁决原则

1. **采信度排序**：官方 > 游戏本体逆向（SO 直出）> 社区数据库 > 推断 > 查不到（不编造）。冲突时取高者，**明确告诉用户"取了谁、弃了谁、依据是什么"**。
2. **未明项处理**：先说当前采用口径与证据等级，再给三选一选项卡（系统默认 / 另一口径 / 我实测过）与实测步骤；用户一手实测覆盖系统默认，跨版本保留。完整步骤见 `agent/references/measurement-guide.md`。

## 红线三：两种口径绝不混用

| 口径 | 用在哪 | 怎么算 |
| --- | --- | --- |
| **周期期望 / 秒伤** | "这套构筑打这个场景平均每秒多少" | 条件伤按对敌模型里的**时间占比**加权 |
| **单跳伤害** | "这一发打多少" | 不摊覆盖率，按命中瞬间目标是否带该状态取 0/1 |

回答单跳问题（`--hit`、`hitZones`）用瞬时口径；回答秒伤、词条收益、循环期望用周期口径。**不要把两者混在一句话里**：不说"45% 易伤覆盖 = 这一发吃 45% 易伤"，不说"这一发暴击了所以秒伤翻倍"。

## 必须记住的乘区规则

```
基础 → 技能倍率 → 主属性 → (元素 + 全伤，加算) → 暴击期望
     → 条件伤(vs，内部加算) → 类型伤 → 技能专属
     → 目标受伤(易伤 30% + 静电 10%/层仅闪电，内部加算) → 减伤
```

- **武器伤害取 stat20（白字）**，直接进伤害基项；攻速只进周期不进单跳。真源公式：`攻击伤害 = trunc((BaseDamage + 倍率×(stat20白字+平伤Damage3)) × (1+主属性/100))`。
- **技能固定伤 BaseDamage**：真源 `DamageEffect.BaseDamage`，不乘倍率但吃后续乘区；反编译实证玩家 49/49 段全为 0，官方工具链也置 0 防双计——**引擎取 0、数值无影响，勿把白字塞进此字段**（白字在 stat20 已乘倍率，塞进去会双计）。此为真源已裁决项，勿再当未决。
- **全伤与元素伤同乘区加算**，不是独立乘区。100% 元素 + 100% 全伤 = ×3.0。
- **易伤 30%** 是目标"受到伤害"通道（真源 ×1.3 硬编码实证）；**"对易伤目标 +X%"** 是攻击者条件伤通道。两者可同时吃，但不能算成同一个。真源 dur=3s，本地 4s 存疑。
- **静电只加闪电伤害、最多 10 层、每层 10%**（1.0.4 真源实锤，2026-11-25 已对齐）：`StaticElectricity` 是 `DamageAmplificationBehavior`，`AmplificationPercent.Base=0.10`、`FilterByDamageType=true`、`AffectedDamageType=3(Lightning)`。旧 5% 是早期推断，已弃用。
  - **结构未决**：静电（放大受伤 Behavior）与易伤（×1.3 VulnerableBehavior）是两种不同机制，真源无合并证据。默认**加算**（`taken:'additive'`），`takenMode:'multiplicative'` 作敏感性对照——回答时说明口径，不武断断言。
- **类型伤**（基础33/强力34/特殊61）三标签在真源是独立加算、命中即加（非单选），但 134 个技能全是单标签，故 `1+agg[ab.type]/100` 等价；三层聚合的 PercentMult 层经核实不影响伤害属性，最终减伤66 仅玩家侧——三项均无需改引擎，详见 `engine-gaps.md`。
- **DoT** 不吃类型伤、不吃 ±10% 浮动；随机浮动当前引擎**未采样**，只是数据声明。
- 上限：暴击率 85%、冷却缩减 **80%**、减伤 90%（1.0.4 StatCap.GetCap 实证，已确认不用再核对）。
- **技能倍率按 1.0.4 真源 AttackScaling 重灌（44 个）**：闪电风暴 **217%**（Base1.5+0.075/级×9，≈用户实测 218%）、横扫 **97%**（70%+3%/级）、寒冰碎片 170%、烈焰斩 340%。勿再用旧 225%/175%/350%。
- **脆裂**：1.0.4 真源实锤——脆裂状态本身无伤害行为（`Brittle` Behaviors=[]），增伤来自传奇戒指 `LegendaryRing8CritDamage`（`ConditionalCritDamage`，暴伤 += 0.05×层数，进暴伤池而非独立乘区）。引擎已按此口径。充能之戒 K 仍无真源数值（MaxBonus=0.5 无 K），维持未决。
- **清算锤（魔翼之锤 / 远古·魔翼之锤）**：1.0.4 真源 `Reckoning(5773)` Stat20 **Type:2 PercentMult**——直接暴击时每层武器伤害 +1%（远古 +1.25%），最多 50 层、持续 3 秒。引擎按 `wdOf = (白字+平伤) × (1+per)^层数` 乘算，层数由用户录入（`--reckoning` / 前端清算层数控件，**不自动按暴击频率脑补稳态层数**）。0 层或未装备时零影响。cli 验证：10 层普通锤 = 基准×1.01^10、远古 = ×1.0125^10。
- **棱彩之心**：1.0.4 真源 `HighestElementalDamageBonus BonusIncrease=0.25`——玩家最高元素伤害加成 +25 个百分点，进元素加算池。单主元素 build 下等价 `fx.ele=25` 归主元素；多元素均衡堆叠且最高项非主元素时是近似，需手动换算。
- **3 件依赖覆盖率的新传奇保持 mechanism（不伪造固定 fx）**：终斩印戒（指定技能×指定状态 +250%，覆盖率未知）、噬魂肩甲（半径3内每敌+3%，Boss按5）、黄金可汗之鞍（仆从装备槽，无玩家 DPS）。三者 note 已给手动折算公式，回答时按覆盖率/敌人数换算或声明无法固定。
- **仆从 39 个**：1.0.4 真源新增仆从中仅收录 8 个带明确 DPS 被动者（腐化魅魔/食人魔/赤沙鳄鱼/赤沙萨提尔/骷髅战士/雪山幼龙/蜘蛛/南瓜王，statId 实证）；其余 29 个为坐骑/防御/资源类，对玩家 DPS 无贡献，不收录。
- **仆从被动成长（2026-11-25 真源复核）**：真源 `SlaveData[].Passives[].Modifier.Value` 有 `Base` 与 `PerLevel`，`Value(L)=Base+PerLevel×(L-1)`。83 个被动 PerLevel≠0（此前"77/77 全 0"是读错字段的误判）。data.js 已按 statId 给 31/39 仆从灌入 `bonusPerLevel=PerLevel/Base`（绝大多数 0.10，即每级相对 1 级 +10%；灰烬领主 CDR=0.0667）。引擎成长等级用 `eff`（含缰绳+5、可超 10；继承槽固定 10 不吃缰绳）。**缰绳赋能推动被动成长**：南瓜王 vs受伤 L1=50%→L10=95%→L15缰绳=120%。CLI `--minion-level` / `--reins`，前端仆从页显示成长后数值与 1 级基准。
- **宝石镶嵌（2026-11-25 真源建模，GemData.json 42 条）**：6 家族（钻石/红宝石/蓝宝石/黄玉/绿宝石/紫水晶）×7 品级（1粗糙球→7完美星形）。每颗按**镶嵌部位类型**给三套加成：武器槽=元素伤%（全家族 10/15/20/25/35/50/70%，按家族元素类型进 `1+元素%+全伤%` 池，**只被同元素技能吃到**）；护甲槽=主属性(红力量/黄敏捷/紫智力)/CDR(钻)/生命%(蓝)/荆棘(绿)，固定值不随等级；饰品槽=对应元素减伤%（生存向不进 DPS）。孔位上限武器3/胸甲2/护腿2/头戒链各1，L30 开放。CLI `--gems '{"1":[{"fam":"topaz","lv":7}]}'`；前端装备页宝石面板。验证：战士火系镶3颗7级红宝石 DPS 146.9万→227.1万，换黄玉回基线（元素按技能精确生效）。
